---
title: job-poller
description: A self-hosted job radar. It polls the public APIs of seven job-board providers for new openings, filters them with configurable rules, scores each survivor against a candidate profile with an LLM (structured, validated output) and sends matches to Telegram within minutes of posting. Finds boards by itself from a Common Crawl seed list, careers-page detection and name discovery. Docker Compose with PostgreSQL, tests and CI.
tech: [Python, PostgreSQL, Docker Compose, Gemini, GitHub Actions]
